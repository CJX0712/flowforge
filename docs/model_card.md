# 模型卡 · FlowForge FlowFuse

> 作者：晨星 · 版本 v0.1.0 · MIT

## 1. 模型概述

**FlowFuse** 是自适应混合归一化流（Mixture of Normalizing Flows），用于**精确似然**
的密度建模与生成采样。

$$\log p(x) = \log\sum_{k=1}^{K}\exp\big(\log\pi_k + \log p_k(x)\big),\qquad p_k = f_k \circ g$$

- $g$：块类型 ∈ {仿射耦合 (RealNVP), 掩码自回归 (MAF)} 构成的复合映射（无参数共享）
- $f_k$：分量 $k$ 的复合映射
- $\pi_k$：softmax 混合权重
- 每个分量由 tanh 单隐层 MLP 参数化的双射器构成，**全部解析梯度**

## 2. 训练

| 项 | 取值 |
|---|---|
| 目标 | 负对数似然（= KL + 常数） |
| 优化器 | Adam + 指数学习率衰减（5e-3 → 3e-4）+ 全局梯度裁剪（范数 5.0） |
| 迭代 / 批大小 | 250 / 256（默认，可在 `FLOWFORGE_ITERS` 等覆盖） |
| 参数量 | ≈1044（与基线 1040 / 1056 **等预算**） |
| 超参选择 | 独立验证集（seed 9042），按验证 NLL 选（块类型, K），K ∈ {1,2,4} |
| 设备 | 纯 CPU，float64，无 GPU、无预训练权重、无网络 |

**为什么必须加 lr 衰减与梯度裁剪**：实测在无衰减时训练 NLL 出现**非单调回弹**
（banana：400 iters → 0.0092，800 iters → 0.0297），会被误读成"方法无效"。
加入衰减+裁剪后单调收敛，同预算下 KL 改善约 2~3 倍。

## 3. 评测协议

| 项 | 说明 |
|---|---|
| 主指标 | `KL(p_true ‖ p_model)`，蒙特卡洛估计，**理论下界 0** |
| 次指标 | 去偏 Sinkhorn 散度 W2、RBF 核 MMD |
| 金标准 | 目标分布提供**解析** `log p_true(x)` |
| 数据切分 | train(seed 变化) / val(9042，仅选参) / test(10007 固定，配对比较) |
| 种子 | 3 个（7 / 11 / 23），报 mean ± std |
| 显著性 | 逐数据集配对，判据 `|Δ̄| > ½(σ₁+σ₂)` |

|---|---|---|---|---|

## 5. 适用与不适用

**适用**：二维（或低维）密度建模、需要**精确似然**、需要可逆采样、需要可验证梯度的场景。

**不适用**（诚实声明）：

1. **目标本身是解析高斯时输给高斯**。`swirl` 分布由"绕原点旋转的高斯"生成，
   旋转不改变高斯，故它**就是**标准高斯 —— 解析高斯是其精确最优解（KL 0.00112），
   任何流都只能逼近（0.00293）。
2. **单峰目标上混合的容量摊薄**。`banana` 上 FlowFuse 比 `maf` 差 0.00087 nats：
   把固定预算摊给 4 个分量后，每个分量只有 2 个块，表达力不足。
   自适应 K 选择把它拉回到只差 0.00087（而非强制 K=4 的更大劣化）。
3. **分段线性样条耦合在共享预算下优化不稳定**。已实现并通过全部不变量检验
   （往返 3.3e-16、logdet 3.2e-10、梯度 7.3e-10），但聚合 KL 0.729 vs 仿射耦合 0.048，
   未纳入主基准。详见 [`known_limitations.md`](known_limitations.md)。
4. **高维未验证**。全部结果限于 2D；高维下耦合流的多尺度结构（splitting）与
   本系统的"总预算均分"策略需重新评估。

## 6. 伦理与限制

- 纯离线研究工具，不访问网络、不含密钥、不含预训练权重。
- 基准为**合成数据**，结论不可直接外推到真实数据；真实场景需自行构造可解析
  或有高精度参考的密度。
