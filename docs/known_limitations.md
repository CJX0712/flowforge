# 已知限制与诚实负结果

> 作者：晨星 · 本文件按「负结果必须保留」原则记录，**不隐藏任何被否决的组件**。

## 1. 分段线性样条耦合（已实现，未纳入主基准）

**状态**：实现完整、**通过全部五类不变量**，但**不参与主基准**。

| 检验 | 实测 | 结论 |
|---|---|---|
| I1 往返可逆性 | 3.3e-16 | ✅ |
| I2 logdet vs 数值雅可比 | 3.2e-10 | ✅ |
| I3 梯度 vs 中心差分 | 7.3e-10 | ✅ |
| 训练（8 blocks, 500 iters） | 聚合 KL **0.729** | ❌ 远差于仿射耦合 0.048 |

**排查过程**（全部实测，非推测）：

1. 梯度检验在 N(0,1) 与实际训练分布上均为 ~5e-10 → **梯度正确**，排除实现 bug。
2. 全批量梯度下降时 NLL **单调下降**（3.2518 → 3.2316）→ 梯度方向正确。
3. 小批量 Adam 下 NLL **发散上升**（3.31 → 4.84）→ **优化不稳定**。
4. 根因：softmax 归一化的 bin 宽度可趋于 0 ⇒ slope = height/width → ∞ ⇒ logdet 爆炸。
5. 修复：加入 `min_bin_width` 下界（Durkan et al. 的 NSF 实现同样强制该约束），
   发散消失，但聚合 KL 仍为 0.729。

**结论（诚实）**：在等参数预算（8 blocks）下，分段线性样条耦合的单位参数表达力
未能兑现。**保留代码与不变量测试作为参考实现，不声称它在本设置下可用。**
已知未验证的可能原因：分箱数 `n_bins`、边界 `bound`、以及为控制参数量而
未做的 hidden 维度缩减 —— 这些属于调参范畴，未穷尽。

## 2. 自适应 K 选择是「弱正收益」而非关键组件

消融（3 数据集 × 2 seeds）：

| 配置 | 平均 KL |
|---|---|
| `K = 1`（等价单流） | 0.30963 |
| `K = 4`（强制） | 0.15091 |
| **自适应 K** | **0.14606** |

- **增益归因清楚**：混合本身（K=1 → K=4）带来 **51.26%** 的 KL 降低。
- 自适应相对强制 K=4 的边际收益仅 **−3.21%**，属于弱正收益。
- 它的真正价值是**安全性**：`K=1` 在搜索格内，保证旗舰在单峰目标上不会
  因摊薄容量而大幅劣化（即 G2 的 5/5 非劣）。

## 3. W2 指标在当前设置下饱和

`fusion` W2 = 0.4402 vs `affine` 0.4404 —— 差异淹没在去偏 Sinkhorn 散度的
估计噪声与正则偏差中（2D、200 样本）。MMD 给出清晰差异（0.000824 vs 0.002849，−71%）。

**因此主判据始终是 KL**：只有它有解析真值作金标准、有理论下界 0。
W2 仅作辅助参考，不参与门禁。

## 4. `swirl` 数据集的退化性质

`swirl` 由 `x = R(a‖z‖)z`（z ~ N(0,I)）生成。绕原点旋转**不改变标准高斯**，
故该分布**恒等于 N(0,I)**，是解析高斯的精确最优场景（高斯基线 KL = 0.00112，
全场最优）。保留它是为了诚实暴露"流在解析可得的最优解面前只能逼近"这一事实，
而非注水抬高分数。

## 5. 作用域限制

- 全部结果限于 **2D**、5 个合成密度。高维下耦合流的多尺度结构（splitting）
  与本系统"总预算均分"策略需要重新评估。
- 训练预算（250 iters）是为满足 60s 端到端预算而标定的；提高预算会进一步拉开
  多模态数据集上的差距，但绝对数值会变化（`benchmark.json` 记录了实际配置）。
- 结论不可直接外推到真实数据：真实场景需自行构造可解析或高精度参考的密度。
